H Header Token type and signing algorithm
Header

The header describes the token's type and the algorithm specified for its signature. 

{
  "alg": "HS256",
  "typ": "JWT"
}
P Payload Claims about the subject and token timestamps
Payload

The payload contains claims about the subject, including when the token was issued and when it expires. 

{
  "sub": "1234567890",
  "name": "Kim",
  "iss": "example.com",
  "aud": "my-api",
  "iat": 1787241600,
  "exp": 1787328000
}
S Signature Signature data (not verified by this tool)
Signature

The signature can be used to check whether a signed token has been altered. Token Peek does not verify signatures. 

K4Q9nJ7xP2fR6m1vZ3tY8pI

cGxlLmNvbSIsInN1YiI6
